# 🔥 Roast Not Found 🔥

Welcome to **Roast Not Found**, a legendary group/project where the burns are sharp, but the jokes never miss their target. We drop savage roasts, epic comebacks, and witty banter that’ll leave you speechless — or laughing out loud! Join us for a relentless stream of humor, where being “roasted” is actually a badge of honor. Can you handle the heat? Let’s get this roast started! 😎🔥

## 🚀 Technologies Used

- 🅱️ Bootstrap 5  
- 🎨 Font Awesome  
- 📜 jQuery  
- ⌨️ Typed.js  
- 🖼️ Nivo Lightbox  
- ✨ Animate.css

- 🔤 Google Fonts  
- 🎨 Custom CSS and Fonts

## 🌟 Features

- 💬 Animated typing intro that welcomes visitors with witty and humorous messages  
- 👥 Team section showcasing profiles with images, roles, and detailed pages  
- 📱 Responsive design powered by Bootstrap for seamless viewing on all devices  
- 🖼️ Lightbox integration for elegant image viewing experience  
- 🔗 Social media links for easy connection and sharing
